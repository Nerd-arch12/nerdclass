AULA INTERATIVA PARA VSCODE.DEV

Mantenha estes arquivos na mesma pasta:
- index.html
- styles.css
- app.js

No vscode.dev, abra uma pasta e envie os três arquivos. O index.html referencia automaticamente styles.css e app.js.

Os links de vídeo exigem internet. As respostas são salvas no navegador com localStorage.
